# 高中语文学习评价与认知诊断系统 V2.1

## ——基于知识—证据—认知状态—干预—迁移闭环的 Learning Assessment OS

---

# 一、系统总体定位与设计理念

## 1.1 核心定位

高中语文学习评价与认知诊断系统面向高中全学段学生、教师及教研场景，以课程标准与学业质量要求为评价依据，以**证据驱动的认知诊断**为核心，以**学生认知状态模型**为统一数据基础，以**自适应学习决策**为干预手段，以**迁移验证**作为学习效果的重要检验方式，构建：

> **知识 → 任务 → 证据 → 认知状态 → 评价 → 决策 → 干预 → 复测 → 迁移 → 新证据**

的持续学习闭环。

系统不以“答题正确率”作为唯一评价依据，而是回答三个核心问题：

1. **学生当前真正掌握了什么？**
2. **当前学习困难最可能来自哪里？**
3. **经过干预之后，是否形成了稳定且可迁移的能力？**

最终将系统从传统的“智能题库/刷题工具”升级为面向高中语文的：

> **Learning Assessment OS（学习评价操作系统）**

---

# 二、总体设计原则

## 2.1 标准独立原则

评价标准独立于算法模型。

课程标准、学业质量要求、考试评价要求以及经过教研确认的评分Rubric构成外部评价依据，模型不得自行修改评价标准。

形成：

> **标准定义“什么是达成”
> 模型估计“学生当前处于什么状态”
> 证据证明“为什么这样判断”**

三者严格解耦。

---

## 2.2 证据优先原则

任何重要诊断结论必须能够追溯到具体证据。

诊断结果至少包含：

> **结论 + 证据 + 置信度 + 不确定性 + 建议**

当现有证据不足以支持可靠判断时，系统允许输出：

> **证据不足 / 暂不可归因**

而不是强行生成一个看似精确的结论。

---

## 2.3 学科适配原则

高中语文不同于高度原子化的数学、物理等学科。

语文具有：

* 知识关联复杂；
* 能力高度综合；
* 同一题目可能涉及多个知识与认知过程；
* 同一知识可以在不同任务中表现出不同能力；
* 能力具有较强的情境依赖；
* 主观题存在评分者差异；
* 学习成果存在明显的迁移和遗忘现象。

因此系统采用：

> **知识网络 + 任务能力 + 认知过程 + 证据模型**

而不是简单的：

> “知识点A → 知识点B → 知识点C”

刚性前置关系。

---

## 2.4 模型解耦原则

DINA、IRT、知识追踪、遗忘模型等模型不直接进行简单数学叠加。

不同模型承担不同职责：

| 模型        | 主要职责             |
| --------- | ---------------- |
| DINA及其扩展  | 认知诊断、技能组合归因      |
| IRT/动态IRT | 总体能力、题目参数和测量尺度校准 |
| 知识追踪      | 学习过程中状态随证据变化的追踪  |
| 遗忘模型      | 长期保持与复习风险估计      |
| 探针模型      | 对错误原因提供额外诊断证据    |
| 迁移模型      | 判断能力是否能够跨情境迁移    |
| 决策模型      | 根据当前状态选择最优干预动作   |

最终通过统一的**证据层 + 学生状态层**进行融合，而不是直接让多个模型相互修改彼此的内部参数。

---

# 三、系统总体架构

系统采用：

> **标准层 → 数据与知识层 → 测量与状态层 → 决策引擎层 → 应用层 → 终端层**

六层架构。

```text
┌──────────────────────────────────────────────┐
│                 终端交互层                    │
│ 学生端 │ 教师端 │ 教研端 │ 管理端             │
└──────────────────────────────────────────────┘
                      ↓
┌──────────────────────────────────────────────┐
│                 学习应用层                    │
│ 诊断 │ 画像 │ 学习方案 │ 训练 │ 复测 │ 写作 │ 成长 │
└──────────────────────────────────────────────┘
                      ↓
┌──────────────────────────────────────────────┐
│                 决策引擎层                    │
│ 评价决策 │ 学习决策 │ 干预策略 │ 教师介入      │
└──────────────────────────────────────────────┘
                      ↓
┌──────────────────────────────────────────────┐
│              测量与认知状态层                 │
│ 认知诊断 │ IRT │ 知识追踪 │ 遗忘 │ 迁移 │ 校准 │
│              统一学生状态模型                 │
└──────────────────────────────────────────────┘
                      ↓
┌──────────────────────────────────────────────┐
│                 数据与知识层                  │
│ 知识图谱 │ 题库 │ 资源库 │ 证据库 │ 标注数据 │ 行为数据 │
└──────────────────────────────────────────────┘
                      ↓
┌──────────────────────────────────────────────┐
│                  标准层                       │
│ 课程标准 │ 学业质量 │ 考试要求 │ 评分Rubric    │
└──────────────────────────────────────────────┘
```

其中最重要的设计是：

> **LLM不位于测量核心链路中，而位于学习内容编排与解释层。**

# 四、评价标准体系

## 4.1 标准层的定位

评价标准不是知识图谱，也不是模型参数，而是系统的“度量基准”。

建立：

> **目标 → 核心素养 → 任务能力 → 认知表现 → 知识资源**

的标准映射体系。

---

## 4.2 五层评价结构

### L5 学习目标层

包括：

* 课程学习目标；
* 学业质量要求；
* 高考相关能力要求；
* 学生个人目标。

### L4 核心素养层

对应高中语文四大核心素养：

1. 语言建构与运用；
2. 思维发展与提升；
3. 审美鉴赏与创造；
4. 文化传承与理解。

### L3 任务能力层

系统重点建模：

* 文言文阅读能力；
* 现代文阅读能力；
* 古代诗歌鉴赏能力；
* 写作表达能力；
* 综合语言运用能力。

这里强调：

> L3是“可观察的任务表现能力”，并不等同于不可直接观察的心理能力本体。

### L2 认知过程层

用于描述完成任务时所涉及的认知活动：

* 识记；
* 理解；
* 分析；
* 推理；
* 评价；
* 迁移；
* 表达。

### L1 知识与资源层

包括：

* 字音字形；
* 文言实词；
* 文言虚词；
* 文言句式；
* 修辞；
* 文本结构；
* 文学常识；
* 文化常识；
* 写作知识；
* 阅读策略等。

---

# 五、学业质量等级体系

系统不直接把某个模型输出的θ值等同于“学业质量等级”。

采用：

> **模型估计 → 标准映射 → 等级判定**

三级机制。

## 5.1 等级定义

| 水平  | 能力定位  | 典型表现           | 证据要求     |
| --- | ----- | -------------- | -------- |
| 水平1 | 基础待提升 | 能完成部分基础知识任务    | 基础证据有限   |
| 水平2 | 基础达成  | 能完成核心知识与常规任务   | 多个独立证据支持 |
| 水平3 | 良好    | 能完成综合任务并进行一定迁移 | 综合+迁移证据  |
| 水平4 | 高水平   | 能处理复杂、开放及跨情境任务 | 多情境稳定证据  |

不预先假定“置信度≥0.8、正确率≥90%”等阈值具有普适有效性。

这些阈值必须通过：

* 标准设定；
* 专家判断；
* 大样本实证；
* ROC/PR分析；
* 校准分析；
* 外部考试锚定；

确定。

因此系统中的阈值属于：

> **待校准参数，而不是理论常数。**

---

# 六、核心数据底座：语文学习知识图谱 LKG

## 6.1 LKG定位

LKG不试图直接描述“学生是什么水平”。

它主要描述：

> **语文知识、认知过程、任务能力、核心素养以及它们之间可能存在的关系。**

学生状态独立存储在“Student Cognitive State Model”中。

因此：

> **知识图谱 ≠ 学生画像 ≠ 题库 ≠ 资源库**

四者通过ID和关系进行连接。

---

# 七、LKG四层结构

## 7.1 L1知识层

记录：

* 知识点；
* 知识属性；
* 适用情境；
* 常见错误；
* 典型例题；
* 相关资源。

关系不采用绝对前置，而采用：

* prerequisite；
* support；
* similarity；
* contrast；
* composition；
* transfer；

等关系类型。

---

## 7.2 L2认知过程层

描述：

> “学生需要执行什么认知动作，才能完成任务？”

例如：

```text
文言实词
   ↓
语境识别
   ↓
义项判断
   ↓
语义推断
   ↓
迁移
```

这一层主要用于：

* 错误归因；
* 任务设计；
* 诊断探针；
* 学习干预。

---

## 7.3 L3任务能力层

描述学生在真实任务中的表现能力。

例如：

```text
文言文阅读能力
├── 文意理解
├── 实词语境判断
├── 虚词辨析
├── 句式分析
├── 翻译
└── 信息概括
```

这些不是完全独立的能力原子，而是可观察任务表现维度。

---

## 7.4 L4核心素养层

用于形成更高层级的评价解释。

例如：

```text
文言文阅读任务表现
        ↓
思维分析能力
        ↓
思维发展与提升
```

需要注意：

> 这种映射属于概率性证据关系，而不是确定性因果关系。

---

# 八、关系模型：从“线性权重”升级为“条件依赖 + 证据模型”

原方案中的：

> 实词0.6 + 虚词0.3 + 句式0.1

属于过度简化。

V2.1采用：

> **结构关系 + 条件概率 + 证据权重**

共同描述知识与能力之间的关系。

例如：

```text
P(TaskSuccess | KnowledgeState,
                    CognitiveProcess,
                    Context,
                    Item)
```

而不是：

```text
TaskAbility =
0.6 × KnowledgeA
+ 0.3 × KnowledgeB
+ 0.1 × KnowledgeC
```

这样才能表达：

* 门槛效应；
* 协同效应；
* 情境效应；
* 认知过程差异；
* 迁移差异。

---

# 九、统一学生认知状态模型

## 9.1 核心原则

原七维状态向量存在一个问题：

> 它同时混合了“能力状态”“统计不确定性”“行为风险”和“错误分类”。

因此V2.1将其拆成三个层次。

---

## 9.2 第一层：能力状态

针对每个知识/任务节点维护：

```text
Knowledge Mastery
Application
Transfer
```

分别表示：

* 知识掌握；
* 常规应用；
* 陌生情境迁移。

---

## 9.3 第二层：证据状态

记录：

```text
Evidence Count
Evidence Diversity
Consistency
Recency
Confidence
```

用于回答：

> “我们有多大把握认为这个状态是真的？”

---

## 9.4 第三层：学习风险状态

包括：

```text
Forgetting Risk
Error Pattern
Learning Friction
Exposure Risk
```

其中：

* 遗忘风险用于复习策略；
* 错误模式用于干预；
* 学习阻力用于学习计划；
* 题目曝光风险用于防止熟题记忆造成虚高。

---

# 十、学生状态示例

以文言虚词“以”为例：

```text
能力状态
├── 知识掌握度：0.78
├── 常规运用：0.63
└── 迁移能力：0.41

证据状态
├── 独立证据数：8
├── 情境覆盖：4
├── 稳定性：0.72
└── 置信度：0.84

学习风险
├── 遗忘风险：0.24
└── 主要错误：
    ├── 语境辨析：0.60
    ├── 知识混淆：0.25
    └── 执行错误：0.15
```

这样避免把：

> “迁移能力0.41”和“置信度0.84”

理解为同一种性质的指标。

---

# 十一、核心评价引擎

## 11.1 评价引擎职责

评价引擎负责：

> **设计测量 → 获取证据 → 更新状态 → 估计不确定性 → 生成评价结果**

不负责：

* 生成学习讲义；
* 自由生成学习路径；
* 修改评价标准。

---

# 十二、自适应测评

## 12.1 测评目标

不是：

> “尽量少做题。”

而是：

> **在满足测量精度的前提下，用尽可能少的有效证据降低关键状态的不确定性。**

因此优化目标为：

$$
\max \frac{\text{Expected Information Gain}}
{\text{Measurement Cost}}
$$

同时加入：

* 内容覆盖约束；
* 难度约束；
* 题目曝光约束；
* 情境多样性约束；
* 测量安全约束。

---

# 十三、DINA、IRT与知识追踪的职责划分

## 13.1 DINA

DINA主要处理：

> “一道题需要哪些技能组合才能完成？”

尤其适合：

* 多知识点题目；
* 技能组合诊断；
* 认知诊断。

但不能将DINA直接理解为完整的高中语文能力模型。

---

## 13.2 IRT

IRT主要负责：

* 题目难度；
* 区分度；
* 学生总体能力尺度；
* 跨试卷能力比较；
* 锚定测试。

动态IRT用于处理能力随时间变化的问题。

---

## 13.3 知识追踪

知识追踪负责：

> 学习过程中学生状态如何随证据发生变化。

因此可以形成：

```text
DINA
  ↓
技能诊断证据

IRT
  ↓
总体能力证据

Knowledge Tracing
  ↓
状态变化证据

Probe
  ↓
错误原因证据

Migration Test
  ↓
迁移证据

        ↓

统一学生认知状态模型
```

---

# 十四、诊断探针机制

## 14.1 探针定位

探针属于：

> **补充诊断证据**

而不是正式考试题的替代品。

因此探针结果原则上不直接用于最终等级判定，而用于解释：

> “为什么错？”

---

## 14.2 三级探针

### Level 1：回忆探针

判断：

> 是否知道。

### Level 2：辨析探针

判断：

> 是否能够在相似情境中区分。

### Level 3：解释探针

判断：

> 是否理解背后的规则和原因。

最终形成：

```text
不知道
   ↓
知道但不会用
   ↓
会用但不稳定
   ↓
常规情境会用
   ↓
陌生情境能够迁移
```

---

# 十五、诊断结论的证据等级

系统不把所有证据视为同等有效。

建议建立：

| 证据等级 | 类型      | 作用   |
| ---- | ------- | ---- |
| A    | 标准化外部测试 | 能力锚定 |
| B    | 独立新题    | 状态验证 |
| C    | 常规训练题   | 状态更新 |
| D    | 探针      | 原因诊断 |
| E    | 行为数据    | 辅助判断 |

因此：

> 连续做对同一道题不能等同于能力提升。

---

# 十六、错误归因模型

错误不直接归为：

> “知识没掌握”。

系统采用多级错误因果链：

```text
答案错误
 ↓
知识因素？
 ↓
认知过程因素？
 ↓
任务策略因素？
 ↓
执行因素？
 ↓
情境因素？
```

形成：

### 知识类

* 不知道；
* 记忆错误；
* 概念混淆。

### 过程类

* 不会分析；
* 不会推理；
* 不会迁移。

### 策略类

* 方法错误；
* 审题策略错误；
* 信息筛选错误。

### 执行类

* 粗心；
* 时间不足；
* 作答格式问题。

系统允许一个错误同时具有多个可能原因。

---

# 十七、证据不足机制

当系统无法区分：

> 知识缺失 vs 方法错误

时，不直接选择其中一个。

输出：

```text
主要假设：
语境辨析能力不足（0.58）

备选假设：
知识义项混淆（0.31）

证据不足：
0.11

建议：
增加2～3个独立情境证据。
```

这样比强行输出：

> “你不会这个知识点”

更加符合教育测量逻辑。

---

# 十八、学习决策引擎

## 18.1 学习决策目标

学习引擎不追求：

> 做更多题。

而追求：

> **单位学习时间内的预期能力增益最大化。**

候选学习动作包括：

* 知识讲解；
* 例题学习；
* 基础训练；
* 应用训练；
* 迁移训练；
* 错题重做；
* 间隔复习；
* 综合训练。

---

# 十九、学习动作效用模型

原来的：

> 知识缺口 × 考点权重 × 预期增益 × 置信度 × 迁移价值 ÷ 学习成本

可以保留作为**启发式排序模型**，但不能直接宣称是“最优学习模型”。

V2.1定义：

$$
Utility(a|s)
=
\frac{
ExpectedGain(a|s)
\times Priority(a)
\times TransferValue(a)
}{
LearningCost(a)
}
$$

其中：

* \(s\)：学生当前状态；
* \(a\)：候选学习动作；
* ExpectedGain：预计状态增益；
* Priority：课程/考试目标优先级；
* TransferValue：对迁移能力的贡献；
* LearningCost：预计时间和认知成本。

后续通过真实学习数据不断校准。

---

# 二十、学习策略不由LLM决定

形成严格的：

```text
学生状态
   ↓
决策引擎
   ↓
学习目标
   ↓
候选学习动作
   ↓
策略选择
   ↓
LLM内容编排
   ↓
学生学习
   ↓
新证据
   ↓
状态更新
```

LLM只负责：

* 内容解释；
* 学习材料组织；
* 错题讲解；
* 表达形式调整；
* 对话式辅导。

LLM不得：

* 修改能力值；
* 修改置信度；
* 修改评价标准；
* 修改模型阈值；
* 自行宣布“已经掌握”；
* 自行决定重要学习目标。

# 二十一、RAG与LLM内容治理

建立：

> **检索 → 证据筛选 → 内容生成 → 主张检查 → 规则验证 → 输出**

流程。

所有知识性内容尽量绑定：

* 来源；
* 教材章节；
* 知识节点；
* 适用范围。

对于文学鉴赏、开放性问题等存在合理多解的内容，不强制生成“唯一正确观点”，而是：

> **主流观点 + 文本证据 + 其他合理解释**

# 二十二、学习路径生成

路径不是一条固定树，而是一个动态策略。

例如：

```text
虚词知识掌握不足
      ↓
基础概念
      ↓
典型语境
      ↓
对比辨析
      ↓
常规应用
      ↓

      ↓
迁移验证
```

如果学生在“典型语境”已经达到稳定掌握，则跳过重复训练。

如果学生在“陌生文本”持续失败，则：

```text
迁移训练
   ↓
诊断原因
   ↓
判断是否基础知识问题
   ↓
必要时返回基础层
```

形成真正的动态路径，而不是机械的：

> Level1 → Level2 → Level3 → Level4。

# 二十三、学习路径熔断机制

原来的“2次失败、3次失败”规则过于机械。

V2.1采用多因素触发：

```text
状态低置信度
+
多个独立证据失败
+
错误模式高度一致
+
连续干预增益不足
```

才触发降维。

同时保留：

### 一级干预

降低任务复杂度。

### 二级干预

更换教学策略。

### 三级干预

教师人工介入。

这比简单的：

> “失败2次降级”

更加符合实际学习过程。

# 二十五、迁移验证体系

迁移不能通过一道陌生题简单判定。

采用四级验证：

### Level 1：回忆

是否记住。

### Level 2：应用

是否能够在熟悉情境使用。

### Level 3：近迁移

是否能够在相似但不同材料中使用。

### Level 4：远迁移/综合

是否能够在新的文本、新任务、新情境中综合使用。

最终定义：

> **掌握 ≠ 会做原题**

而是：

> **掌握 = 独立证据 + 稳定表现 + 情境变化 + 一定迁移能力**

# 二十六、遗忘与长期保持

艾宾浩斯曲线不作为学生遗忘过程的绝对真实模型。

系统将其作为：

> **复习策略的初始先验**

随着真实数据积累，根据学生个人：

* 答题间隔；
* 重做结果；
* 遗忘速度；
* 复习次数；
* 错误情况；

估计个体化遗忘风险。

形成：

> 群体先验 → 个体参数 → 个性化复习。

## 27.4 人机一致性校准

* 不同分数段一致性；

# 三十四、核心KPI体系

不再采用单一正确率。

| ---- | ---------------------- | ------------ |
| 测量质量 | Diagnostic Accuracy    | 诊断与外部标准的一致程度 |
| 测量效率 | Measurement Efficiency | 达到目标精度所需测量成本 |
| 学习效果 | Learning Gain          | 干预前后能力变化     |

| 长期效果 | Retention              | 延迟测试后的保持水平   |

预测概率与实际表现是否一致。

# 三十七、典型案例：高二学生文言文阅读薄弱

学生进入：

> “文言文阅读专项诊断”。

系统首先获取基础证据。

```text
虚词
知识掌握：0.55

常规运用：0.42

迁移：0.30

当前置信度：0.71
```

系统没有立即宣布：

> “学生不会虚词。”

而发现：

```text
证据：
3道虚词题错误

探针：
回忆探针：正确
辨析探针：错误
解释探针：部分正确
```

因此系统形成：

> **主要假设：语境辨析能力不足。**

而不是：

> “虚词知识缺失。”

随后决策引擎选择：

```text
虚词对比辨析
 ↓
相似语境训练
 ↓
短文本应用
 ↓
陌生文本迁移
```

LLM只负责生成和组织学习内容。

7天后：

```text
基础任务：90%
常规应用：85%
近迁移：75%
```

系统认为：

> 常规应用已经形成较稳定掌握。

但由于迁移证据仍有限，不直接宣布：

> “该能力完全掌握”。

而进入：

> **延迟迁移验证**

阶段。

若一周后新材料中仍保持稳定表现，才提高迁移状态与整体评价置信度。

最终形成：

```text
原始诊断
 ↓
原因诊断
 ↓
针对性干预
 ↓
即时复测
 ↓
迁移测试
 ↓
延迟验证
 ↓
状态更新
```

这才构成完整的认知诊断学习闭环。

# 三十九、最终设计原则

整个系统最终遵循六条核心原则：

> **第一：标准决定评价边界，模型不能修改标准。**

> **第二：证据决定诊断可信度，没有证据就允许“不知道”。**

> **第三：模型负责估计状态，不负责创造事实。**

> **第四：LLM负责解释和编排，不负责核心评价与决策。**

> **第五：学习效果必须通过独立证据和迁移验证，而不是刷题正确率证明。**

> **第六：系统不是“题库+AI”，而是“测量—决策—干预—验证”的学习操作系统。**

因此，高中语文学习评价系统的核心技术路线最终收敛为：

$$
\boxed{
Curriculum\ Standard
\rightarrow
Knowledge\ Graph
\rightarrow
Evidence
\rightarrow
Cognitive\ State
\rightarrow
Measurement
\rightarrow
Decision
\rightarrow
Intervention
\rightarrow
Transfer
\rightarrow
Evidence
}
$$

其核心竞争力不再是：

> **“AI能生成多少题、多少讲义。”**

而是：

> **“系统能否持续、可信地回答：学生现在会什么、为什么不会、下一步学什么，以及学完之后是否真的形成了可迁移能力。”**

这构成高中语文 Learning Assessment OS 的核心技术壁垒。
