## 二、填空题（每题4分，共24分）
9. **$2\sqrt{3}$** （原式 $= 2\sqrt{3} - 2 \times \frac{\sqrt{3}}{2} + 2 = \sqrt{3} + 2$。*注：原题设计计算后为 $\sqrt{3}+2$，此处修正答案为 $\sqrt{3}+2$*。抱歉，按题意：$\sqrt{12}=2\sqrt{3}$，$2\sin60^\circ=\sqrt{3}$，$|-2|=2$，故结果为 $\sqrt{3}+2$。）
10. **0** （代入 $x=1$ 得 $1-2+a+b=0 \Rightarrow a+b=1$；代入 $x=-1$ 得 $-1-2-a+b=0 \Rightarrow b-a=3$。联立得 $a=-1, b=2$，$a+b=1$。*修正：$a+b=1$，非0*。填 **1**。）
11. **$f(x) = -3x - 1$** （令 $x$ 替换为 $-x$ 得 $f(-x) + 2f(x) = -3x + 1$，联立原式解方程组即可）

14. **$m \le 0$ 或 $m \ge 4$** （$|AB| = \frac{\sqrt{\Delta}}{|a|} = \sqrt{(m-1)^2 - 4m} = \sqrt{m^2 - 6m + 1} \ge 2 \Rightarrow m^2 - 6m - 3 \ge 0$，解得 $m \ge 4$ 或 $m \le -1$。*修正：解方程 $m^2-6m-3 \ge 4 \Rightarrow m^2-6m-7 \ge 0 \Rightarrow (m-7)(m+1) \ge 0$，故 $m \le -1$ 或 $m \ge 7$*）

## 三、解答题（共52分）

**15. （本题满分12分）**
**解：**
令 $2x-1=0$ 得 $x=\frac{1}{2}$；令 $x+1=0$ 得 $x=-1$。
因此分三个区间讨论：
① 当 $x < -1$ 时，原不等式化为 $-(2x-1) + (-(x+1)) < 4$
即 $-3x < 4 \Rightarrow x > -\frac{4}{3}$。
结合 $x < -1$，解集为 $-\frac{4}{3} < x < -1$。 ...... (4分)
② 当 $-1 \le x < \frac{1}{2}$ 时，原不等式化为 $-(2x-1) + (x+1) < 4$
即 $-x + 2 < 4 \Rightarrow x > -2$。
结合 $-1 \le x < \frac{1}{2}$，解集为 $-1 \le x < \frac{1}{2}$。 ...... (4分)
③ 当 $x \ge \frac{1}{2}$ 时，原不等式化为 $(2x-1) + (x+1) < 4$
即 $3x < 4 \Rightarrow x < \frac{4}{3}$。
结合 $x \ge \frac{1}{2}$，解集为 $\frac{1}{2} \le x < \frac{4}{3}$。 ...... (4分)
综上所述，原不等式的解集为 $\{x \mid -\frac{4}{3} < x < \frac{4}{3}\}$。 ...... (12分)

**16. （本题满分12分）**
**解：**
（1）因为图象交 $x$ 轴于 $A(-1, 0)$，$B(3, 0)$，可设解析式为 $y = a(x+1)(x-3)$。
又过点 $C(0, -3)$，代入得 $a(1)(-3) = -3$，解得 $a = 1$。
故二次函数解析式为 $y = x^2 - 2x - 3$。 ...... (4分)
（2）二次函数 $y = x^2 - 2x - 3 = (x-1)^2 - 4$。
其顶点坐标为 $(1, -4)$。向上平移 $k$ 个单位后，解析式为 $y = (x-1)^2 - 4 + k$。
要使平移后的图象与 $x$ 轴只有一个交点，则顶点在 $x$ 轴上。
即 $-4 + k = 0$，解得 $k = 4$。 ...... (4分)
（3）由（2）知，平移后的解析式为 $y = (x-1)^2$。
其顶点坐标为 $D(1, 0)$。
令 $x=0$，得 $y=1$，即与 $y$ 轴交点为 $E(0, 1)$。
在 $\triangle DOE$ 中，$OD = 1$（$D$ 到 $y$ 轴的距离），高为 $OE = 1$。
所以 $S_{\triangle DOE} = \frac{1}{2} \times 1 \times 1 = \frac{1}{2}$。 ...... (4分)

**17. （本题满分14分）**
**解：**
（1）$[2.7] = 2$，$[-3.2] = -4$，故原式 $= 2 + (-4) = -2$。 ...... (3分)
（2）设 $[x] = n$ ($n$ 为整数)，则 $x = n + \alpha$，其中 $0 \le \alpha < 1$。
原方程化为 $n + n + \alpha = 2.5$，即 $2n + \alpha = 2.5$。
因为 $0 \le \alpha < 1$，所以 $0 \le 2.5 - 2n < 1$。
解得 $2n \le 2.5$ 且 $2n > 1.5$，即 $0.75 < n \le 1.25$。
因为 $n$ 为整数，所以 $n = 1$。
此时 $\alpha = 2.5 - 2 = 0.5$。
所以 $x = n + \alpha = 1.5$。 ...... (6分)
（3）当 $x \in [0, 1)$ 时，$[x] = 0$，$y = x$；
当 $x \in [1, 2)$ 时，$[x] = 1$，$y = x - 1$。
图象为两段斜率为 $1$ 的线段，端点分别为 $(0,0)$ 到 $(1,1)$（含左端点，不含右端点），以及 $(1,0)$ 到 $(2,1)$（含左端点，不含右端点）。（图略，画对给分） ...... (3分)
该函数具有周期性，其周期 $T = 1$。 ...... (2分)

**18. （本题满分14分）**
**解：**
（1）根据题意，利润 $y = $ 销售收入 $-$ 总成本。
$y = p \cdot x - (20000 + 100x)$
$= (500 - 0.5x)x - 20000 - 100x$
$= -0.5x^2 + 400x - 20000$ ($0 < x \le 500$ 且 $x \in \mathbb{Z}$)。 ...... (4分)
（2）$y = -0.5(x^2 - 800x) - 20000 = -0.5(x - 400)^2 + 60000$。
因为 $-0.5 < 0$，抛物线开口向下，有最大值。
当 $x = 400$ 时，$y_{max} = 60000$。
因为 $400 \le 500$，符合实际意义。
所以当年产量为 $400$ 台时，年利润最大，最大年利润为 $60000$ 元。 ...... (5分)
（3）加入政府补贴 $t$ 元/台后，利润函数变为：
$y_1 = y + tx = -0.5x^2 + (400+t)x - 20000$。
其对称轴为 $x = \frac{400+t}{2 \times 0.5} = 400 + t$。
由于抛物线开口向下，若要使利润在产量最大时（即 $x=500$ 处）取得最大值，
必须满足对称轴 $x = 400 + t \ge 500$。
解得 $t \ge 100$。
所以，$t$ 的取值范围是 $t \ge 100$。 ...... (5分)
