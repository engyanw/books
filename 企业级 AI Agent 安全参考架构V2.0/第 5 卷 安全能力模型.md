## 1. 能力模型总览
### 1.1 定位与核心价值
安全能力模型是整套架构的能力量化拆解体系，实现「能力域→子能力→实现组件→核心 KPI→成熟度等级」的逐层映射，是企业开展安全能力现状评估、建设规划、厂商选型、效果验证的统一标尺。

本模型解决企业 AI 安全建设的三类核心痛点：
1. **底数不清**：全面盘点 AI Agent 安全所需的完整能力项，避免能力遗漏与防护盲区
2. **优先级不明**：基于风险等级明确能力建设优先级，指导资源合理分配
3. **效果不可度量**：为每项能力设定可量化的指标，实现安全效果可衡量、可验证、可优化

模型对齐 NIST 网络安全框架（CSF）、零信任成熟度模型、AI 风险管理框架（AI RMF）等国际标准，可与企业现有安全能力体系无缝衔接。

### 1.2 设计原则
1. **业务驱动原则**：能力建设围绕业务场景风险展开，高风险场景对应高等级能力，不搞过度建设。
2. **分级分类原则**：所有能力按成熟度划分为五级，企业可按需选择对应等级，避免一刀切。
3. **可度量原则**：每项核心能力均配套可量化的 KPI，效果可验证、可对比、可追溯。
4. **落地导向原则**：能力项均对应可落地的实现组件与技术方案，而非纯概念性描述。
5. **兼容复用原则**：充分复用企业现有安全能力，AI 专属能力做增量补充，避免重复建设。

### 1.3 整体能力框架
模型共包含 8 大一级能力域、32 项二级子能力、100+ 三级能力点，完整覆盖 AI Agent 安全从底层基建到上层运营的全链路需求。

| 一级能力域 | 能力定位 | 对应架构平面 |
|------------|----------|--------------|
| 身份与访问安全 | 权限管控基石，零信任核心载体 | 零信任安全平面 |
| 运行时安全防护 | AI 原生安全核心主防线 | 运行时安全平面 |
| 数据与模型安全 | 核心资产保护体系 | 数据安全平面 + AI 能力平面 |
| 基础设施安全 | 底层可信底座 | 基础设施安全平面 |
| 威胁检测与运营 | 安全运营闭环中枢 | 安全治理平面 |
| 合规与治理 | 合规与风险管控体系 | 安全治理平面 |
| 可观测性能力 | 度量与排障支撑 | 全链路横切能力 |
| 基础支撑能力 | 公共基础组件 | 统一控制平面 + 公共组件 |

## 2. 核心能力域详解
### 2.1 身份与访问安全域
#### 能力域概述
以 Agent 原生身份为核心的全链路访问控制体系，是零信任架构在 AI 场景的落地载体，承担身份管理、授权管控、访问隔离的核心职责。

#### 子能力矩阵
| 二级子能力 | 核心实现组件 | 关键 KPI 指标 | 对应成熟度 |
|------------|--------------|---------------|------------|
| Agent 工作负载身份 | SPIRE / 云厂商原生身份 / 自研身份服务 | Agent 身份覆盖率、身份全局唯一率、身份颁发成功率 | L2 起步，L3 全覆盖 |
| 三级身份穿透 | 身份映射服务、上下文透传机制 | 全链路身份可追溯率、责任定位准确率 | L3 级能力 |
| 动态授权引擎 | OPA / Casbin / 商用策略引擎 | 权限粒度（接口级/参数级/字段级）、授权决策延迟 | L2 基础规则，L3 动态属性授权 |
| 身份联邦与对接 | IAM 集成、SSO 对接、身份同步 | 现有身份体系复用率、账号同步准确率 | L2 级能力 |
| 特权访问管理 | 特权操作审批、临时权限、会话审计 | 高危操作人工审批率、永久权限占比、特权操作审计率 | L3 级能力 |
| 微隔离执行 | 网络策略、服务网格、应用层隔离 | 隔离粒度、越权访问拦截率、策略生效延迟 | L2 网络级，L3 应用级 |
| 持续信任评估 | 风险引擎、信任评分模型 | 信任评估维度数、权限动态调整响应时间 | L4 级能力 |

## 3. 安全能力成熟度分级标准
### 3.1 五级成熟度总定义
采用五级成熟度模型，对齐行业通用分级标准，企业可对照定位自身当前水平，明确提升路径。

| 成熟度等级 | 等级名称 | 整体特征 | 典型企业画像 |
|------------|----------|----------|--------------|
| L1 | 初始级 | 零散防护、无体系、依赖人工、风险不可控 | 试点探索期企业，仅零散使用 AI 工具，无专项安全 |
| L2 | 基础级 | 核心能力有底座、单点防护生效、流程初步建立 | 推广成长期企业，核心场景有基础安全，能力分散 |
| L3 | 体系级 | 全链路纵深防御、体系化运营、合规全面满足 | 规模化生产期企业，全场景覆盖，形成完整防护体系 |
| L4 | 优化级 | 智能化运营、数据驱动优化、攻防常态化 | 成熟运营企业，安全自进化，效率与效果持续提升 |
| L5 | 领先级 | 自适应安全、内生安全、行业标杆水平 | 头部领先企业，安全与业务深度融合，引领行业实践 |

### 3.2 各域成熟度分级对照
| 能力域 | L1 初始级 | L2 基础级 | L3 体系级 | L4 优化级 | L5 领先级 |
|--------|----------|----------|----------|----------|----------|
| 身份与访问 | 无统一身份，复用用户权限 | Agent 基础身份，静态角色权限 | 三级身份穿透，动态属性授权 | 持续信任评估，自适应权限 | 分布式身份，跨域互信体系 |
| 运行时安全 | 无专项防护，依赖模型内置 | 基础注入检测，简单内容审核 | 全链路多层防护，工具网关+沙箱 | 自适应防护强度，智能规则生成 | 内生安全，模型原生防护 |
| 数据与模型 | 基础存储加密，无专项保护 | 分类分级打标，基础脱敏 | 全链路加密脱敏，水印溯源 | 隐私计算规模化，密态推理 | 全密态计算，原生隐私保护 |
| 基础设施 | 基础云安全，无 AI 专项 | 容器安全，基础漏洞扫描 | 全栈基建安全，供应链管控 | 机密计算规模化，供应链全链路 | 芯片级内生安全，全密态底座 |
| 威胁运营 | 无专项检测，人工排查 | 基础告警，人工分析响应 | 全链路检测，标准化运营流程 | 智能研判，自动化响应，常态化演练 | 自进化攻防博弈，全自动闭环 |
| 合规治理 | 无专项合规，事后整改 | 基础合规对齐，人工审计 | 全合规满足，体系化治理 | 自动化合规审计，全生命周期治理 | 合规原生嵌入，自适应监管要求 |
| 可观测性 | 零散监控，无统一标准 | 基础指标日志，排查靠经验 | 全链路可观测，统一标准 | 智能根因分析，效果量化度量 | 可观测原生嵌入，数字孪生可视化 |

## 4. 能力评估与建设指引
### 4.1 成熟度自评流程
企业可按以下四步完成自身 AI 安全能力成熟度自评，明确现状与差距：
1. **场景盘点**：梳理所有 Agent 业务场景，按风险等级分级，明确核心保护对象。
2. **逐项评分**：对照能力矩阵，对每项子能力按五级标准打分，形成现状能力雷达图。
3. **差距分析**：对比目标成熟度要求，识别能力缺口，按风险影响排序。
4. **规划制定**：结合业务节奏与资源投入，制定分阶段能力建设计划。

### 4.2 能力建设优先级排序
基于风险驱动原则，按以下优先级排序建设，实现投入产出比最优：
1. **第一优先级（必建）**：解决高危风险的核心能力，包括：
   - Agent 基础身份与权限管控
   - 提示注入与越狱检测
   - 工具调用基础鉴权
   - 核心数据加密与脱敏
   - 基础审计日志
2. **第二优先级（应建）**：完善纵深防御、提升体系化水平的能力，包括：
   - 全链路运行时多层防护
   - 动态授权与微隔离
   - 数据分类分级与防泄露
   - AI 原生威胁检测与运营
   - 基础合规体系建设
3. **第三优先级（优建）**：提升效率、增强高级防护的能力，包括：
   - 机密计算与隐私计算
   - 自动化响应与智能运营
   - 全链路供应链安全
   - 自适应防护与持续信任评估
4. **第四优先级（前瞻）**：前沿探索、构建长期竞争力的能力，包括：
   - 内生安全体系
   - 全密态计算
   - 分布式身份与跨域互信

### 4.3 不同规模企业落地建议
- **小型企业**：目标成熟度 L2，优先建设第一优先级能力，复用云厂商原生能力，控制投入。
- **中型企业**：目标成熟度 L3，完成前两优先级能力建设，构建完整防护体系，支撑业务规模化。
- **大型集团企业**：目标成熟度 L4，全量建设前三优先级能力，布局第四优先级前沿技术，构建行业领先能力。
